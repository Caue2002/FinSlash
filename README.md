# FinSlash

Projeto acadêmico de portfólio que apresenta uma interface interativa para explorar serviços da AWS e personagens selecionáveis.

## Executar

Abra `index.html` em um navegador. O projeto usa HTML, CSS e JavaScript sem etapa de build.
